# Вторая статья: как вставить в Хабр

Картинки лежат в публичном репозитории и подставляются в текст прямыми ссылками вида
`https://raw.githubusercontent.com/pseudex-ai/habr-images/main/docs/img/habr-02/<файл>.png`.
Копируешь текст целиком и вставляешь в редактор: картинки подтягиваются сами.

## Состав

  * `habr-READY.md` — текст статьи;
  * `cover-780x440.png` — обложка для ленты;
  * пять картинок внутри текста: три семейства корпусов, лицензии русских корпусов,
    две шумовые лестницы, перекос отбора, карта разметки.

## Что указать в форме

| поле | значение |
|---|---|
| Тип | Статья |
| Язык | Русский |
| Аудитория | Data Scientists |
| Хабы | Искусственный интеллект · Natural Language Processing · Машинное обучение |
| Формат | Обзор |
| Сложность | Средний |
| Перевод | нет |

Ключевые слова: бенчмарк, разметка данных, NER, PII, NEREL, оценка качества,
открытые данные, LLM, маскирование персональных данных, вызов инструментов
