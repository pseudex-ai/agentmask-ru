# Timeweb Cloud — API и документация

## Доступ

- **API:** `https://api.timeweb.cloud/api/v1`, заголовок `Authorization: Bearer <токен>`.
- **Токен:** `~/pseudex-timeweb-token.txt`, строка `TIMEWEB_TOKEN=…`, права 600.
  Никогда не печатать его в ответ, не класть в репозиторий, не передавать в
  `curl` через аргументы с `-u`; только заголовком из переменной:

  ```bash
  T=$(cut -d= -f2- ~/pseudex-timeweb-token.txt)
  curl -s -H "Authorization: Bearer $T" https://api.timeweb.cloud/api/v1/servers | python3 -m json.tool
  ```

- **Документация:** https://timeweb.cloud/api-docs — SPA, `openapi.json` публично не
  отдаётся (проверено 14.09.2026: `/api-docs/openapi.json`, `/openapi.json` — 404).
  Читать раздел через WebFetch с вопросом про конкретный эндпоинт, либо открыть в
  браузере. Ответ по неизвестному эндпоинту сначала проверять GET-ом: 404 значит
  «нет в этом API» (например `/dns-zones`, `/vpcs`, `/s3/buckets` — 404;
  `/locations` — 403 для api-ключа).

## Что известно и проверено (14.09.2026)

| Эндпоинт (GET) | Что отдаёт |
|---|---|
| `/account/status` | состояние аккаунта, блокировки |
| `/servers` | список; `servers[].networks[].ips[]` — IPv4/IPv6, `status` (`on`/`off`) |
| `/servers/{id}` | всё о сервере: `os`, `cpu`, `ram` (МБ), `disks[].size` (МБ), `preset_id`, `is_allow_root_ssh_pass`, `cloud_init`, `node_name` |
| `/servers/presets` | пресеты с ценами — для вопросов «сколько стоит 8 ГБ» |
| `/ssh-keys` | ключи в аккаунте (`773175 pseudex-prod`) |
| `/projects`, `/images`, `/floating-ips`, `/balancers`, `/databases` | соответствующие ресурсы |

Наш сервер: **`pseudex-prod`, id `9102523`**, Санкт-Петербург, Ubuntu 24.04,
4 vCPU × 3.3 ГГц, 8 ГБ, 80 ГБ NVMe, IPv4 `201.34.151.187`,
IPv6 `2a03:6f01:1:2::2:3c72`. Для входа на него — скилл `prod-server`.

Изменяющие операции (перезагрузка, снимок, смена пресета, удаление) — через
`POST/PATCH/DELETE` на тех же путях (`/servers/{id}/action` с `{"action":
"reboot"}` и т.п.); **перед каждой — подтверждение владельца в чате**, и
сначала свериться с документацией по точной форме тела: угадывать поля нельзя.

## Как отвечать на вопрос по Timeweb

1. Если вопрос про НАШ ресурс — сначала GET по API, потом ответ по факту.
2. Если вопрос про возможность/цену/лимит — WebFetch раздела документации с
   точным вопросом; цитировать, что там написано, а не пересказывать по памяти.
3. Если эндпоинт не найден в API — сказать прямо: «в API этого нет, только
   панель», и назвать, где в панели (вкладки сервера: Дашборд · Доступ · Сеть ·
   Консоль · Бэкапы · Образы · Конфигурация · История).

## Что мы намеренно НЕ берём у Timeweb

Бэкапы (480 ₽), аварийная копия, отмена удаления, DDoS-защита — копии
делаются restic'ом в Yandex Object Storage с проверкой из CI, машина
пересоздаётся `deploy/bootstrap.sh`. Решение 14.09.2026; не предлагать включать.
