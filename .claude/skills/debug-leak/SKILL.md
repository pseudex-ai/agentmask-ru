# Расследование дефекта маскирования

## Сначала назвать класс — они чинятся в разных файлах

**Утечка.** Настоящее значение дошло до модели. Худший класс.

**Фейк в инструменте.** Круг разорван: подмена не разрешилась обратно, и клиент
вызвал инструмент значением, которого не существует.

**Переразметка.** Замаскировано то, что не персональные данные. Ломает клиенту
его собственный документооборот, и выглядит это как «ваш продукт сломал мне
поиск», а не как наша ошибка.

**Расщепление личности.** Один человек получил несколько псевдонимов или,
наоборот, двое получили один. Второе — единственный отказ, который продукт
считает недопустимым.

## Лестница изоляции: сверху вниз, не перепрыгивая

```python
# ЛИЗИНГ БАНДЛА ПЕРВОЙ СТРОКОЙ, ВСЕГДА. Без него детектор поднимает
# BundleNotLeased — это не поломка окружения, а замысел: движок без
# арендованных ассетов не детектирует ничего.
import sys; sys.path.insert(0, ".")
from testkit import load_dev_bundle; load_dev_bundle()
from pseudex.detect_all import Detector
d = Detector()
```

Дальше по лестнице:

```python
# 1. Детекция вообще нашла?
t = "<строка>"
print([(s.entity_type, t[s.start:s.end]) for s in d.detect(t)])

# 2. Нашла, но не то? Кто из распознавателей дал спан:
from pseudex.address import _regex_candidates, _natasha_candidates
from pseudex.assets import ASSETS
a = ASSETS.get().address
print([(t[s:e], core) for s, e, core in _regex_candidates(t, a)])

# 3. Нашла и потеряла? Проверь suppress и разрешение перекрытий:
#    context.suppress() идёт ДО разрешения — порядок важен.

# 4. Спан есть, круг рвётся? Смотри волт:
from pseudex.vault import Vault, canonicalize
v = Vault(":memory:", "x")
print(canonicalize("NAME", "<значение>"), "->", v.tokenize("<значение>", "NAME"))
from pseudex.redact import unmask_text
print(unmask_text(f"текст {token}", v))
```

Не начинай с четвёртого шага. Половина «сломанного круга» — это на самом деле
спан, найденный не целиком.

## Обязательный первый вопрос: это регрессия?

```bash
git stash push -q pseudex licensing
python3 -c "<та же проба>"          # поведение на HEAD
git stash pop -q
```

Совпало — дефект **пре-существующий**, и это меняет приоритет и формулировку.
За сегодня так снялись «8 марта 5», «Сочи 25» и «улицах Каира»: все три
выглядели как свежая поломка и не были ею.

## Где живёт каждый класс

**Утечка** — почти всегда покрытие, а не полнота. Спан нашёлся частично, хвост
ушёл. Смотри разницу этих двух чисел в `bench/agentpii/score.py`, там же дамп
«найдено частично».

**Фейк в инструменте** — четыре подкласса, и прибор их называет сам:
`починен пробел` и `починена латиница` — **не дефекты**, это продукт складывает
гомоглиф и восстанавливает пропущенный пробел, чтобы в CRM ушла форма, которая
там найдётся. Настоящие — `форма изменена` (канонизация выдумала) и
`вернулась часть`.

**Переразметка** — `test_overmasking.py`, `bench/eval_external_precision.py` и
A/B по объёму прозы. Наши наборы её не видят по построению: они не содержат
обычного делового текста.

**Расщепление** — `СОГЛАСОВАННОСТЬ` в AgentPII. Смотри `_linked_token`,
`_corresponding_part` и форму подмены: если `name_shape` прочла имя как
фамилию, оба слота схлопнутся в один и второе упоминание получит свой токен.

## Что почти всегда оказывается причиной

- **`parse(word)[0]`** там, где разборы стоят вровень.
- **Регистр**: правило работает на «Ленина» и не работает на «ленина».
- **Пунктуация**: правило работает с запятой и разваливается без неё. Сегодня
  так нашлось, что строчная ветка принимала первые цифры телефона за номер дома.
- **Слово-подсказка вне окна** или на символ дальше, чем допускает паттерн.
- **Перекрытие**: спан нашёлся, но проиграл соседу по приоритету и утащил его.
- **WAL**: если ищешь ПД в файле базы — они могут быть в `-wal` до контрольной
  точки. Грепать каталог, а не файл.

## Чего не делать

**Не смягчать прибор.** Если проверка ловит дефект, а её вердикт неудобен —
чинится код, а не проверка. Послабление в скорере прячет ровно тот дефект,
который оно прощает: «позвоните Игорю» → «Игорю» имеет ту же форму, что и
законная починка, и это склонённое имя в CRM клиента.

**Не чинить по одному примеру.** Найди класс. Один вход, который заработал, —
это не правило, а совпадение.

**Не расширять сигнал, чтобы дотянуться.** Если правилу не хватает
доказательства, добавь другой сигнал, а не ослабь имеющийся. Ослабленный найдёт
то, что просили, и ещё половину языка.

Дальше — скилл `detect-change` для самой правки и `measure` для доказательства,
что не стало хуже.
