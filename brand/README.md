# Брендбук pseudex

> **Файлы внутри называют продукт veilgate.** Это оригинальный экспорт из
> Claude Design, сделанный до переименования, и он намеренно НЕ правится:
> исторический артефакт, переписанный задним числом, перестаёт быть
> доказательством того, что было решено. Дизайн — палитра, сетка, знак, тексты
> — от смены имени не изменился.

Оригинальный handoff из Claude Design. **Источник истины по внешнему виду** —
если реализация и эти файлы расходятся, правы эти файлы (или их надо изменить
здесь, а не в коде).

Это прототипы, а не продакшен-код. Так сказано в их собственном README:
«recreate them pixel-perfectly in whatever technology makes sense; don't copy
the prototype's internal structure». Отгрузить их клиенту нельзя — они тянут
React с CDN, чего запрещает и наш CSP, и требование работать в контуре без
интернета.

## Что где

| файл | что это |
|---|---|
| `pseudex-local-ui.dc.html` | локальный интерфейс, 6 экранов, все состояния |
| `pseudex-landing.dc.html` | лендинг целиком |
| `pseudex-logo.dc.html` | **4 варианта знака** + фавиконы + светлая версия |
| `support.js` | runtime прототипов, «GENERATED — do not edit». Дизайна не содержит |
| `uploads/*.png` | визуальные референсы (лендинг herdr) |

## Принятые решения

**Знак — вариант 02 · SWAP.** Две одинаковые скруглённые формы внахлёст:
настоящее и подменённое. Он и стоит в интерфейсе, на лендинге и в фавиконе.
Остальные три в `pseudex-logo.dc.html` — отклонённые варианты, оставлены как
запись выбора.

**Шрифт — Inter, а не Archivo из макета.** У Archivo нет кириллического
сабсета вообще, а интерфейс полностью русский: макет, набранный им, потерял бы
собственную типографику на каждом слове. Inter — тот же нейтральный гротеск,
есть вес 900 для заголовков, кириллица полная.

## Как посмотреть прототипы

Откройте `.dc.html` в браузере с интернетом: `support.js` подтянет React с CDN и
отрисует интерактивную версию с переключателями состояний. Именно из-за этой
зависимости прототипы и не могут быть продуктом.
