# Third-party marks

Used only to identify integrations, not to imply endorsement or completed compatibility.
Assets are served locally; visiting the page makes no brand/CDN request.

- `codex.png`: official OpenAI-published Codex extension icon, from
  https://marketplace.visualstudio.com/items?itemName=openai.chatgpt
  Asset URL fetched 2026-10-15:
  https://openai.gallerycdn.vsassets.io/extensions/openai/chatgpt/26.51007.21434/1791508178385/Microsoft.VisualStudio.Services.Icons.Default
  The supplied white artwork on opaque black is converted to an alpha mask
  (source luminance multiplied by source alpha); geometry is unchanged.
  This is the OpenAI mark used by the official Codex listing, not an invented terminal logo.
- `claude.svg`: the first, symbol-only path of the official Claude Code docs lockup:
  https://mintcdn.com/claude-code/c5r9_6tjPMzFdDDT/logo/light.svg
  Discovered on https://code.claude.com/docs/en/overview on 2026-10-15.
  Original symbol geometry retained; colour supplied by CSS mask.

- `google.png`: official Google G asset from Google's static branding CDN:
  https://www.gstatic.com/images/branding/product/1x/googleg_48dp.png
  Fetched 2026-10-15. Geometry unchanged; rendered as an alpha mask in grey.
  Identifies Google in the Google Gemini model-provider example.

The marks render in the same neutral grey site token in light and dark themes.
The generic CLI card is not a brand and retains a neutral terminal symbol.
