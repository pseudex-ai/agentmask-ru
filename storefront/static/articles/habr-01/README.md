# Картинки статьи для Хабра

Файлы отдаются витриной по адресу `/static/articles/habr-01/<имя>.png` и
подставляются в статью обычными ссылками `https://pseudex.ru/static/...`.
Исходники лежат в `docs/articles/img/`.

Почему так, а не data-URI внутри markdown: `data:` в `src` не показывают ни
GitHub, ни большинство редакторов, они рисуют alt вместо картинки. Ссылка на
https работает везде, включая вставку в редактор Хабра.
