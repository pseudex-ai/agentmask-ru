# Cloud.ru `guardrails-llm-filter`

Открытый маскирующий обратный прокси на Go (Apache-2.0, `github.com/cloud-ru-tech/guardrails-llm-filter`).
Ставит плейсхолдеры `<TYPE_N>` и восстанавливает их в аргументах вызова инструмента.

Измеряется адаптером `openai_proxy`: прокси нужно указать наш фальшивый провайдер
как upstream, поэтому провайдер поднимается на фиксированном порту и слушает все
интерфейсы — из контейнера `127.0.0.1` ведёт в сам контейнер.

```sh
# 1. Поднять прокси, направив его на фальшивого провайдера
docker compose up -d

# 2. Прогнать корпус
agentmask run --adapter openai_proxy --name cloudru \
    --base-url http://127.0.0.1:8080/v1 \
    --upstream-bind 0.0.0.0:8099 \
    --out results/

docker compose down
```

**Linux.** `host.docker.internal` там не резолвится по умолчанию; в `compose.yml`
оставлен `extra_hosts`, который это чинит. Если не помогает — `network_mode: host`
и `GUARDRAILS_UPSTREAM_BASE_URL=http://127.0.0.1:8099/v1`.

**Что стоит знать, читая цифры.** Фильтр объявляет инвариант fail-open: «любая
внутренняя ошибка пропускает трафик, а не ломает его» (README проекта). На оси
`ошибок` это выглядит как ноль, а на оси `скрыто` — как пропущенное значение;
бенчмарк не считает это ошибкой прокси, он считает это утечкой, потому что
инструмент и модель видят ровно это.

Версия образа и дайджест попадают в манифест прогона: пропишите их в
`--notes`, если собираете образ сами.
