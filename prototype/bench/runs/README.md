# Замеры

Один каталог на прогон, имя — дата. Внутри:

| файл | что это |
|---|---|
| `manifest.json` | git-версия, время, код возврата и длительность каждого шага, sha256 входных корпусов |
| `SUMMARY.md` | заголовочные числа всех шагов в одном документе |
| `NN-имя.txt` | полный вывод шага, как он был напечатан |
| `live-*/` | живой прогон: `*.jsonl` по случаю, `*.judge.jsonl` след судьи, `*.spend.tsv` леджер трат, `*.json` отчёт |

Пересобрать сводку из сохранённого прогона:

```bash
python3 bench/summarize_run.py bench/runs/2026-09-01
```

## Что здесь НЕ хранится и почему

Датасеты (`dataset.json`, `dirty.json`, речевые корпуса) — их нет в репозитории
и не будет: часть под CC BY-NC, часть весит десятки мегабайт, и все они
порождаются заново командой из `manifest.json`. Хранится РЕЗУЛЬТАТ и то, чем он
получен, а не вход.

## Как читать ненулевой код возврата

Он означает «порог не взят», а не «скрипт упал». Порог — это обещание продукта,
и шаг, который его не берёт, обязан быть виден в CI как красный. Причина всегда
напечатана в самом файле.
