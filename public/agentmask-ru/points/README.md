# Реестр очков

Одна строка — один вклад, один файл на pull request (`points/<номер PR>.jsonl`),
чтобы записи не конфликтовали при слиянии.

```json
{"github": "octocat", "новый случай": 3, "ревью": 2}
```

| вклад | очки |
|---|---|
| новый случай | 1 |
| первый случай в новой страте (регистр × тип × семья инструментов) | +2 |
| ревью чужого PR | 1 |
| найденный и починенный дефект скорера | 2–10 |
| прогон системы с полными наблюдениями | 1 |

Порог соавторства в статье — **8 очков**. Реестр живёт и после статьи: бенчмарк,
где после публикации нечего заработать, умирает — так закончился BIG-bench.
