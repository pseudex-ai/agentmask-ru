# Pseudex

Обратимый шлюз маскирования ПДн для LLM-агентов (лицензируемый; авторы этого
бенчмарка — его команда, см. «Раскрытие» в корневом README). Подставляет
значения, сохраняющие формат, и восстанавливает настоящие в аргументах вызова
инструмента.

Измеряется адаптером `openai_proxy` — **ровно тем же путём, что Cloud.ru и
LiteLLM**: движок получает запросы по HTTP и не знает, что его измеряют.

```sh
# 1. Пробный ключ: регистрация на https://pseudex.ru, 14 дней без оплаты
export PSEUDEX_LICENSE_KEY=ps_live_…

# 2. Поднять прокси, направив его на фальшивого провайдера
docker compose up -d

# 3. Прогнать корпус
agentmask run --adapter openai_proxy --name pseudex \
    --base-url http://127.0.0.1:8000/v1 \
    --upstream-bind 0.0.0.0:8099 \
    --out results/

docker compose down
```

**Версия.** Образ закреплён тегом в `compose.yml`; другой берётся через
`PSEUDEX_IMAGE=…`. Тег и дайджест попадают в манифест прогона через `--notes`.

**Linux.** `host.docker.internal` там не резолвится по умолчанию; в `compose.yml`
оставлен `extra_hosts`, который это чинит. Если не помогает — `network_mode: host`
и `PSEUDEX_UPSTREAM=http://127.0.0.1:8099/v1`.

**Что стоит знать, читая цифры.** Шлюз fail-closed: ошибка маскирования — это
5xx, а не пропущенный текст. На оси `ошибок` это видно как ненулевое число, на
оси `скрыто` — нет. Подстановки нормализуются (именительный падеж имени,
словарное написание улицы, свёртка омоглифов), поэтому в строке `круг` часть
значений возвращается не буква в букву, а в канонической форме; в отчёте они
считаются отдельно как «вернулось починенным».
