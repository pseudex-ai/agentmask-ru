# AgentMask-RU

**Ломает ли шлюз маскирования персональных данных работу LLM-агента с инструментами?**

[Таблица результатов](leaderboard.md) · [Как добавить случай](CONTRIBUTING.md) · [English](README.en.md)

Маскировать текст — половина задачи. Агент ВЫЗЫВАЕТ ИНСТРУМЕНТЫ, а инструменту нужно
настоящее значение: `create_order(phone="+7 907 …")` не найдёт заказ по подстановке.
Шлюз обязан вернуть настоящее значение в аргумент и не сломать при этом ничего
остального. Ни NER-корпуса, ни корпуса маскирования ПД, ни бенчмарки вызова
инструментов этого не измеряют.

## Обзор

272 случая · 680 значений ПД · 624 негатива · русский язык

| | |
|---|---|
| **Семьи** | `create_order` · `check_status` · `verify_identity` · `refund` · `send_sms` · `second_mention` |
| **Регистры** | `clean` (как в форме) · `chat` (строчными, без разделителей) · `sloppy` (одна описка) |
| **Типы ПД** | ФИО · телефон · адрес · дата рождения · СНИЛС · ИНН · паспорт · карта |
| **Ярусы имён** | `common` · `tail` · `diminutive` · `foreign` |
| **Адаптеры** | `noop` · `placeholder_regex` · `openai_proxy` · `presidio` · `llm_guard` · `pseudex_sidecar` |

Восемь строк отчёта, которые **не складываются в общий балл**:

| строка | что значит |
|---|---|
| `leak` | значение изменено до того, как его увидела модель |
| `coverage` | ни один кусок настоящего значения не дожил до модели |
| `typed` | тип определён верно (если маскировщик отдаёт спаны) |
| `round_trip` | инструмент получил настоящее значение — из тех, что были скрыты |
| `end_to_end` | то же по всем значениям: «агент не сломан» |
| `overmask` | номер заказа, трек, сумма, дата документа, голый город не тронуты |
| `consistency` | второе упоминание человека получило ту же подстановку |
| `stability` | подстановка не менялась между запросами |

Шлюз, который маскирует всё, выигрывает первую строку и проигрывает две последние.
У каждого числа — точный интервал Клоппера–Пирсона; безошибочная строка печатает, что
она **сертифицирует**, а не «100%».

## Установка

```sh
pip install -e .                 # ядро: стандартная библиотека + jsonschema
pip install -e ".[presidio]"     # для адаптера presidio
pip install -e ".[llm_guard]"    # для адаптера llm_guard
```

## Запуск

```sh
# библиотека
agentmask run --adapter presidio

# любой OpenAI-совместимый маскирующий прокси
agentmask run --adapter openai_proxy --name мой-шлюз \
    --base-url http://localhost:8080/v1 --upstream-bind 0.0.0.0:8099

# записать прогон и пересобрать таблицу
agentmask run --adapter presidio --out results/
agentmask leaderboard
```

Прокси измеряется **без модели**: харнесс поднимает фальшивого провайдера, прокси шлёт
ему замаскированные сообщения — ровно то, что увидела бы модель, — скриптовая «модель»
копирует увиденное в вызов инструмента, прокси восстанавливает аргументы, харнесс
читает, что получил бы инструмент.

Рецепты для чужих шлюзов — в [`baselines/`](baselines/).

## Результаты

[leaderboard.md](leaderboard.md) — семь систем на одном корпусе, с парными сравнениями
по McNemar. Каждый прогон в `results/<система>/` содержит пообъектные наблюдения: любой
может пересчитать строки своей арифметикой.

## Корпус

Генерируется детерминированно; `--check` доказывает, что committed-версия — ровно та,
что даёт это зерно.

```sh
agentmask build --seed 20260920 --out cases/
agentmask build --seed 20260920 --out cases/ --check
```

Значения — Wikidata (CC0), NEN (CC BY 4.0), mimesis и Faker (MIT). Телефоны — из
**резервных кодов DEF** российского плана нумерации (Приказ Минцифры № 75): валидные для
libphonenumber и не принадлежащие ни одному абоненту. Эталон — каноническая форма
**того, что написано**. Атрибуции — [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

## Проверки

```sh
agentmask gates          # семь гейтов
pytest -q                # 29 тестов
```

Гейты защищают от корпуса, который не может провалиться: `G6` требует, чтобы
passthrough проходил каждый случай, `G7` — чтобы наивный regex оставлял след везде, где
случай не объясняет, почему не может, `G8` следит за наполнением страт.
`tests/test_gates.py` ломает каждое свойство нарочно и требует, чтобы проверка
покраснела.

## Раскрытие

Бенчмарк написан командой **Pseudex** — шлюза, который он же измеряет.

- Правило отбора случаев вычислимо без какого-либо маскировщика и зафиксировано до прогонов.
- Пулы значений не пересекаются с рабочими словарями Pseudex по построению; манифест
  нашего прогона печатает долю имён корпуса, которые наш газетир всё-таки знает.
- Наш прогон помечен `vendor-submitted`, содержит полные наблюдения и не отзывается.
- Движок не воспроизводится из этого репозитория: он лицензируемый. До публичного
  пробного ключа наша строка — заявление вендора, а не независимый замер.

## Чего бенчмарк не измеряет (v0.1)

Стриминг · ПД, приходящие обратно из инструмента · память агента между диалогами ·
восстановление подстановки, которую модель просклоняла или транслитерировала ·
эквивалентность по TOST.
